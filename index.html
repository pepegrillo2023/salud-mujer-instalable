Compartir esta app

Esta app guarda tus datos solo en este dispositivo/navegador: nada se sube a internet. Para que otra persona tenga su propia copia vacía (con sus propios datos, guardados en su propio dispositivo), subí este archivo HTML a un hosting propio (por ejemplo Netlify, GitHub Pages o similar) y compartí esa URL por link o generando un código QR acá abajo.

Pegá la URL para generar el código QR. Si no cargás una URL, se usa la dirección actual de la página (si la abriste desde un servidor).

Instalar como acceso directo

    Las edades, la periodicidad y los especialistas sugeridos son orientativos, según guías generales de salud. No reemplazan la indicación de tu médica o médico de cabecera, que es quien mejor puede ajustarlos a tu historia clínica.

    Tus datos —incluidas las fechas, notas y los archivos que adjuntes— se guardan solo en este teléfono/navegador (no se envían a ningún servidor). Si cambiás de celular, de navegador o borrás los datos del sitio, se pierden: no hay forma de recuperarlos desde otro lado, salvo que antes hayas exportado una copia de seguridad con el botón "Copia".
